# Тріангуляція Делоне довільної 2D області (mesh2d)

Програма для розбиття двовимірної області на трикутні скінченні
елементи. Реалізує всі вимоги завдання «Розбиття області на
трикутні скінченні елементи»:

| № | Вимога | Де реалізовано |
|---|--------|-----------------|
| 1 | Тріангуляція задовольняє умову Делоне; згущення сітки; контроль мінімального кута | `mesh2d/triangulation.py` |
| 2 | Нумерація вузлів/трикутників; масив зв'язності; оптимальна нумерація (мінімізація ширини стрічки) | `mesh2d/connectivity.py` |
| 3 | Маркування вузлів межі за типом граничної умови | `mesh2d/geometry.py`, `mesh2d/triangulation.py` |
| 4 | Тріангуляція довільної області (не лише індивідуального завдання) | `mesh2d/geometry.py` |
| 5 | Обчислення локальних і глобальних матриць МСЕ, розв'язання задачі | `mesh2d/fem.py`, `variant1.py` |
| 6 | Графічний інтерфейс користувача, порівняння результатів | `app.py` (Streamlit) |

---

## 1. Встановлення

Потрібен Python 3.9+. Встановіть залежності:

```bash
pip install -r requirements.txt
```

Файл `requirements.txt` містить:

```
triangle>=20250106   # Python-обгортка над C-бібліотекою Triangle (Дж. Шюvarchuk) -- ядро тріангуляції Делоне
numpy>=1.24           # робота з масивами координат/індексів
matplotlib>=3.7       # візуалізація сітки та портрету матриці
streamlit>=1.60       # графічний веб-інтерфейс користувача
```

> **Примітка щодо `triangle`:** це офіційна Python-обгортка (пакет
> `triangle` на PyPI) над класичним генератором сіток *Triangle*
> Джонатана Шюvarchuka (J.R. Shewchuk, 1996) -- тим самим, який
> лежить в основі багатьох університетських і промислових МСЕ-пакетів.
> Вона реалізує побудову тріангуляції Делоне та алгоритм Рупперта
> (Ruppert's Delaunay refinement) для якісного згущення сітки.
> При встановленні через pip код компілюється локально (Cython),
> тому потрібен встановлений компілятор C (на Linux/macOS зазвичай
> вже є; на Windows -- поставте "Build Tools for Visual Studio",
> або використовуйте WSL).

## 2. Запуск графічного інтерфейсу

```bash
.venv/bin/streamlit run app.py
```

Відкриється сторінка в браузері (типово `http://localhost:8501`).
У бічній панелі:

1. Оберіть **тип області**: прямокутник, прямокутник з отвором,
   круг або довільний багатокутник (вводяться координати вершин).
2. Задайте **мінімальний кут** (контроль якості) і **максимальну
   площу трикутника** (контроль густини сітки).
3. За бажанням увімкніть **зону локального згущення** (кругову або
   прямокутну ділянку з дрібнішою сіткою всередині області).
4. Натисніть **«Побудувати сітку»**.
5. У вкладках переглядайте саму сітку, маркування граничних умов і
   ефект оптимальної нумерації вузлів (портрет матриці до/після).
6. Увімкніть **«Режим порівняння двох варіантів»**, щоб побудувати
   дві сітки з різними параметрами (густина, геометрія) і порівняти
   їх пліч-о-пліч (кількість вузлів/трикутників, ширина стрічки тощо).
7. Кнопка **«Завантажити сітку як .txt»** експортує вузли (з
   RCM-нумерацією та маркерами) і трикутники у текстовий файл.

`app.py` демонструє геометричну частину проєкту: сітку, граничні
маркери та оптимальну нумерацію. Чисельний розв'язок конкретної задачі
методом скінченних елементів будує `variant1.py` (див. розділ 9).

## 5. Як реалізовано тріангуляцію Делоне та контроль якості

`DelaunayMesher.triangulate()` формує рядок ключів для бібліотеки
`triangle` (файл `triangulation.py`, метод `_build_switches`):

* `p` -- тріангулювати задану межу (PSLG) як обов'язкові
  ("constrained") відрізки -- сторони трикутників повинні лежати
  точно на межі області;
* `D` -- **conforming Delaunay**: гарантує, що результат є
  справжньою тріангуляцією Делоне (жодна вершина не потрапляє в
  описане коло жодного трикутника), а не лише "constrained"
  наближенням;
* `q<кут>` -- вмикає **алгоритм Рупперта** (Ruppert's Delaunay
  refinement): поки в сітці є трикутник з кутом, меншим за заданий,
  генератор вставляє нові ("Штейнерові") вузли в центри описаних кіл
  "поганих" трикутників і перебудовує сітку локально, зберігаючи
  умову Делоне. Так забезпечується **гарантований мінімальний кут**
  (практично надійно -- до ~33-34°, що є теоретичною межею збіжності
  цього алгоритму);
* `a<площа>` -- обмежує максимальну площу будь-якого трикутника
  (глобальне **згущення сітки**): менше значення -> більше вузлів
  -> дрібніша сітка;
* `A` (разом із `regions`) -- **локальне** згущення: підобласті
  (задані точкою всередині) отримують СВІЙ ліміт площі, незалежний
  від глобального. У `geometry.py` метод `add_refinement_zone_circle`
  /`_rect` додає замкнений внутрішній контур (технічну лінію з
  маркером 0, що не є фізичною межею) і точку-регіон із дрібнішим
  лімітом площі всередині нього.

Функція `verify_delaunay()` (у `triangulation.py`) додатково
перевіряє умову Делоне **незалежно від бібліотеки**: для кожного
трикутника обчислює центр і радіус описаного кола за формулою через
детермінант і перевіряє, що жодна інша вершина сітки не потрапляє
всередину цього кола. Це "чесна" перевірка результату, а не сліпа
довіра до `triangle`.

## 6. Масив зв'язності та маркування граничних умов

* `build_connectivity(mesh)` (`connectivity.py`) формує:
  * `node_to_triangles[k]` -- список трикутників, що містять вузол `k`;
  * `adjacency[k]` -- множину вузлів, суміжних із вузлом `k` (мають з
    ним спільне ребро хоча б одного трикутника). Саме цей граф і є
    "матрицею зв'язності" сітки: два вузли `i, j` дають ненульовий
    елемент `A_ij` матриці жорсткості МСЕ тоді й лише тоді, коли вони
    входять в один спільний трикутник (або збігаються).
* Маркування граничних умов: кожному відрізку межі в `Domain`
  присвоюється ціле число -- маркер (0 = внутрішня лінія, не фізична
  межа; 1, 2, 3... -- різні типи граничних умов). Бібліотека `triangle`
  автоматично переносить ці маркери з відрізків на вузли, які їм
  належать (`vertex_markers` у результаті), і `Mesh.node_markers`
  зберігає це для кожного вузла. Метод `Mesh.boundary_nodes(marker)`
  повертає індекси вузлів конкретного маркера -- готово для підстановки
  крайових умов Діріхле/Неймана у МСЕ-розв'язувач.

## 7. Оптимальна нумерація вузлів: алгоритм Катхілла-Маккі (RCM)

### 7.1 Навіщо це потрібно

При складанні глобальної матриці жорсткості МСЕ ненульовий елемент
`A[i][j]` виникає для кожної пари вузлів `i, j`, що входять в один
скінченний елемент. Якщо вузли пронумеровані "як попало", суміжні
(в геометричному сенсі) вузли можуть мати дуже різні номери -> ненульові
елементи розкидані далеко від головної діагоналі -> **ширина стрічки**

```
B = max по всіх ненульових A[i][j] з |i - j|
```

виходить великою. Для стрічкового (`banded`) або профільного
(`skyline`) зберігання розрідженої матриці потрібно виділяти пам'ять
під ВСІ елементи в межах цієї стрічки, навіть нульові -- тому велике
`B` різко збільшує витрати пам'яті (`O(N*B)`) і час прямого розв'язання
СЛАР (`O(N*B^2)`). Мета -- перенумерувати вузли так, щоб суміжні вузли
отримали БЛИЗЬКІ номери, мінімізуючи `B`.

### 7.2 Реалізація (файл `mesh2d/connectivity.py`), крок за кроком

Усе написано "з нуля" на чистому Python/NumPy (без `scipy`), щоб
логіку алгоритму було видно повністю:

1. **`compute_bandwidth(adjacency)`** -- рахує поточну `B` за графом
   суміжності: для кожного вузла `i` бере максимум `|i - j|` серед
   усіх його сусідів `j`, і бере максимум по всіх вузлах.

2. **Пошук хорошого стартового вузла -- `_find_pseudo_peripheral_node`**
   (спрощений алгоритм Джорджа-Лю, George-Liu). Результат
   Катхілла-Маккі сильно залежить від того, з якого вузла починати
   обхід: найкраще починати з вузла на "периферії" графа (з
   максимальним ексцентриситетом). Алгоритм:
   * виконує обхід у ширину (BFS) від поточного вузла і будує рівні
     (`_bfs_levels`) -- групи вузлів на відстані 0, 1, 2, ... кроків;
   * бере вузол ОСТАННЬОГО рівня з НАЙМЕНШИМ степенем як кандидата
     на новий старт;
   * якщо глибина обходу (кількість рівнів) від кандидата не
     збільшилась порівняно з попереднім -- зупиняється (знайдено
     достатньо "периферійний" вузол), інакше повторює процес із
     кандидатом.

3. **`cuthill_mckee_order(adjacency)`** -- власне алгоритм Катхілла-Маккі:
   * стартовий вузол (знайдений на кроці 2) отримує номер 0 і
     потрапляє в чергу (`deque`);
   * далі це звичайний обхід у ширину (BFS), АЛЕ на кожному кроці
     сусіди поточного вузла, які ще не відвідані, СОРТУЮТЬСЯ ЗА
     ЗРОСТАННЯМ ЇХНЬОГО СТЕПЕНЯ і саме в такому порядку додаються
     в чергу й отримують наступні номери;
   * ідея сортування за степенем: вузли з малим степенем (мало
     сусідів) обробляються першими, що на практиці "стягує" сусідні
     вузли ближче один до одного в підсумковій нумерації і зменшує
     розкид номерів у групі суміжних вузлів;
   * якщо граф сітки складається з кількох незв'язних компонент
     (буває для областей зі складною топологією), кожна компонента
     нумерується окремо, по черзі.

4. **`reverse_cuthill_mckee_order(adjacency)`** -- бере результат
   кроку 3 і **розвертає масив номерів у зворотному порядку**
   (`order[::-1]`). Це і є RCM. Математично доведено (Джордж, 1971),
   що обернений порядок ніколи не дає гіршої ширини стрічки, ніж
   прямий Катхілл-Маккі, а на практиці майже завжди дає меншу --
   тому саме RCM, а не "прямий" CM, застосовується в реальних
   МСЕ-пакетах, і саме його використано в даній програмі.

5. **`apply_renumbering(mesh, order)`** -- застосовує знайдену
   перестановку до сітки: масив `order[new_position] = old_index`
   перетворюється на обернене відображення `old_to_new` (функція
   `permutation_to_mapping`), після чого:
   * координати й маркери вузлів переставляються `nodes[order]`;
   * індекси вузлів у масиві трикутників переписуються через
     `old_to_new[triangles]` (векторизовано, без явних циклів).

6. **`renumber_with_rcm(mesh)`** -- зручна функція "все в одному":
   будує граф зв'язності, рахує `B` до перенумерації, виконує RCM,
   рахує `B` після -- саме її викликає `app.py` для показу метрик
   "Ширина стрічки до/після" на екрані.

### 7.3 Приклад ефекту (з `demo.py`)

Для пластини з отвором і локальною зоною згущення (261 вузол):

## 8. Універсальність (довільна область)

Область описується не жорстко "зашитими" координатами, а через
клас `Domain` у форматі PSLG (вершини + відрізки + маркери + отвори
+ регіони густини). Це дозволяє тріангулювати:

* прямокутник, круг (готові фабрики `rectangle_domain`, `circle_domain`);
* багатозв'язні області з отворами (`rectangle_with_hole_domain` --
  пластина з круглим отвором, демонструє множинну зв'язність);
* абсолютно довільний простий багатокутник, введений користувачем
  через координати вершин у GUI (`polygon_domain`);
* будь-яку комбінацію з локальними зонами згущення довільної форми
  і кількості.

Отже, алгоритм НЕ обмежений фігурою з індивідуального завдання.

## 9. Завдання №3: обчислення матриць МСЕ

Цей розділ є короткою теоретичною базою для звіту та захисту третього
завдання. Реалізація знаходиться у `mesh2d/fem.py`, а конкретний приклад
задачі -- у `variant1.py`.

### 9.1. Диференціальна постановка

Для демонстраційного варіанта розглядається трикутна область

$$
\Omega = \operatorname{conv}\{(0,0),(1,0),(0,1)\}.
$$

Потрібно знайти функцію $u(x_1,x_2)$, яка задовольняє рівняння

$$
-\frac{\partial^2 u}{\partial x_1^2}
-\frac{\partial^2 u}{\partial x_2^2}=2
\quad \text{в } \Omega.
$$

На двох катетах задана головна умова Діріхле:

$$
u=0.
$$

На гіпотенузі задана природна умова Неймана:

$$
\frac{\partial u}{\partial n}=0.
$$

У програмі катети мають маркер `1`, а гіпотенуза -- маркер `2`.

У загальному випадку код підтримує задачу

$$
-\operatorname{div}(A\nabla u)+d u=f \quad \text{в } \Omega,
$$

де $A=\operatorname{diag}(a_{11},a_{22})$, а на межі використовується
умова Робіна

$$
\beta\frac{\partial u}{\partial n}+\sigma u=\psi.
$$

Діріхле та Нейман є окремими випадками цієї умови.

### 9.2. Слабка форма

Нехай $v$ -- тестова функція, яка дорівнює нулю на ділянці межі
Діріхле. Помножимо диференціальне рівняння на $v$ та проінтегруємо
по області. Після інтегрування частинами отримуємо:

$$
\int_\Omega \left(
a_{11}u_{,1}v_{,1}+a_{22}u_{,2}v_{,2}+d uv
\right)\,d\Omega
+\int_{\Gamma}\frac{\sigma}{\beta}uv\,d\Gamma
=\int_\Omega fv\,d\Omega
+\int_{\Gamma}\frac{\psi}{\beta}v\,d\Gamma.
$$

Варіаційна постановка: знайти $u$ у просторі допустимих функцій таку,
що ця рівність виконується для всіх допустимих $v$.

Для задачі з варіанта 1 маємо $a_{11}=a_{22}=1$, $d=0$, $f=2$.
На межі Неймана $\sigma=0$, $\psi=0$, тому крайовий інтеграл не додає
внеску до системи.

### 9.3. Лінійний трикутний елемент

Кожен трикутник має три вузли з глобальними номерами $i$, $j$, $m$.
На ньому розв'язок апроксимується лінійно:

$$
u_h^{(e)}(x_1,x_2)=
\varphi_i(x_1,x_2)q_i+
\varphi_j(x_1,x_2)q_j+
\varphi_m(x_1,x_2)q_m,
$$

або у матричному вигляді

$$
u_h^{(e)}=N_e q_e,
\qquad
N_e=(\varphi_i,\varphi_j,\varphi_m).
$$

Функції форми є барицентричними координатами: кожна дорівнює одиниці
у своєму вузлі та нулю в інших. Їхні градієнти сталі всередині
лінійного трикутника.

Для координат трьох вершин обчислюються коефіцієнти

$$
b_i=y_j-y_m,\quad
b_j=y_m-y_i,\quad
b_m=y_i-y_j,
$$

$$
c_i=x_m-x_j,\quad
c_j=x_i-x_m,\quad
c_m=x_j-x_i.
$$

Позначимо через $\Delta=2S_e$ подвоєну площу трикутника. У коді
орієнтація всіх трикутників нормалізується проти годинникової стрілки,
а координати кожного елемента зберігаються у `triangle_coordinates`.
Площа додатково перевіряється за формулою Герона.

### 9.4. Локальні матриці та вектор навантаження

Локальна матриця жорсткості:

$$
K_e=\frac{1}{2\Delta}
\left(a_{11}bb^T+a_{22}cc^T\right).
$$

Локальна матриця реакції або маси:

$$
M_e=\frac{d\Delta}{24}
\begin{bmatrix}
2&1&1\\
1&2&1\\
1&1&2
\end{bmatrix}.
$$

Якщо $f$ апроксимується його вузловими значеннями
$f_e=(f_i,f_j,f_m)^T$, то локальний вектор правої частини дорівнює

$$
Q_e=\frac{\Delta}{24}
\begin{bmatrix}
2&1&1\\
1&2&1\\
1&1&2
\end{bmatrix}f_e.
$$

Для граничного ребра довжини $L$ з умовою Робіна додаються:

$$
R_e=\frac{\sigma}{\beta}\frac{L}{6}
\begin{bmatrix}2&1\\1&2\end{bmatrix},
\qquad
P_e=\frac{\psi}{\beta}\frac{L}{2}
\begin{bmatrix}1\\1\end{bmatrix}.
$$

У `local_matrices()` обчислюються $K_e$, $M_e$, $Q_e$, а у
`local_boundary_matrices()` -- $R_e$ і $P_e$.

### 9.5. Збірка глобальної системи

Нехай у трикутника локальні вузли мають глобальні номери
$[i,j,m]$. Тоді кожен елемент локальної матриці додається у відповідну
позицію глобальної матриці:

$$
A[I_a,I_b]\mathrel{+}=K_e[a,b]+M_e[a,b],
\qquad
F[I_a]\mathrel{+}=Q_e[a],
$$

де $I=(i,j,m)$, а $a,b\in\{0,1,2\}$ -- локальні індекси.

Після обробки всіх трикутників і граничних ребер отримуємо систему

$$
Aq=F.
$$

Тут $q$ -- вектор шуканих значень $u$ у вузлах сітки. Саме це робить
функція `assemble(mesh, prob)`. Функція `solve()` розв'язує систему
методом `numpy.linalg.solve`.

Внутрішні технічні ребра мають маркер `0` і не додають крайових
внесків. Крайова збірка виконується лише для ребер, маркер яких присутній
у словнику граничних умов задачі.

### 9.6. Як у коді задаються граничні умови

У `variant1.py` задача задається так:

```python
prob = Problem(
  a11=1.0, a22=1.0, d=0.0, f=2.0,
  bcs={
    1: BoundaryCondition.dirichlet(0.0),
    2: BoundaryCondition.neumann(0.0),
  },
)
```

У цій реалізації умова Діріхле імітується методом великого коефіцієнта:

$$
\beta=\varepsilon=10^{-5},\qquad
\sigma=M=10^5,\qquad
\psi=M u_0.
$$

Для $u_0=0$ це фактично змушує вузлові значення на межі бути близькими
до нуля. Умова Неймана задається наближенням

$$
\beta=M,\qquad \sigma=\varepsilon,\qquad \psi=M g.
$$

Для нульового потоку $g=0$ крайовий внесок практично зникає.

### 9.7. Теоретичне існування та єдиність

Слабка задача має вигляд: знайти $u\in V$, для якої

$$
a(u,v)=\ell(v)\quad \forall v\in V.
$$

За стандартних припущень $A$ симетрична та додатно визначена:

$$
\xi^T A\xi\geq \alpha |\xi|^2,\qquad \alpha>0,
$$

коефіцієнти обмежені, а права частина є неперервним функціоналом.
Тоді білінійна форма є неперервною та коерцитивною на просторі $V$.
За теоремою Лакса--Мільграма існує єдиний слабкий розв'язок.

Для конкретної задачі єдиність також забезпечується ненульовою ділянкою
Діріхле на катетах. Вона виключає довільну додаткову сталу функцію,
яка могла б залишатися при чистій нульовій умові Неймана.

Після скінченно-елементної апроксимації та коректного врахування
умов Діріхле отримується невироджена система $Aq=F$, тому вузловий
вектор $q$ також визначається однозначно.

### 9.9. Питання, які можуть поставити на захисті

**Чому потрібна слабка форма?**
Вона знижує вимоги до гладкості розв'язку та дозволяє апроксимувати його
простими функціями на окремих елементах.

**Що таке $\Delta$?**
Це подвоєна площа трикутника: $\Delta=2S_e$.

**Як локальна матриця потрапляє у глобальну?**
За глобальними номерами трьох вузлів конкретного трикутника.

**Чим відрізняються умови Діріхле та Неймана?**
Діріхле задає значення самої функції і є головною умовою. Нейман задає
нормальну похідну або потік і входить у праву частину слабкої форми як
природна умова.

**Що перевіряє похибка?**
Різницю між вузловими значеннями чисельного розв'язку та контрольним
аналітичним рядом, обчислену у вузлах сітки.
